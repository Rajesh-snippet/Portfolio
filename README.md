# Rajesh Sarma Bordoloi — Portfolio

A professional dark developer portfolio built with React + Vite.

## Stack

- React
- Vite
- Lucide React
- Responsive CSS
- No backend required

## Run locally

```bash
npm install
npm run dev
```

Then open the local URL shown by Vite.

## Build

```bash
npm run build
npm run preview
```

## Before deploying

1. Edit `src/data.js`.
2. Replace `your.email@example.com`.
3. Replace the LinkedIn placeholder.
4. Add your real `public/resume.pdf`.
5. Add project demo MP4 files under `public/videos/`.
6. Replace placeholder GitHub/live-demo URLs with the actual project links.

## Deploy on Vercel

1. Push this repository to GitHub.
2. Import the repository into Vercel.
3. Framework: Vite.
4. Build command: `npm run build`.
5. Output directory: `dist`.
6. Deploy.

Vercel will create a live URL and can automatically redeploy when you push changes.

## Suggested demo-video format

Keep each project demo around 30–90 seconds:
1. Show the problem.
2. Show the application.
3. Show the model/system working.
4. Show the result.
5. End with the stack and outcome.
